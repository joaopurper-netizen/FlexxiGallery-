2. On-Device ML Pipeline

Face Recognition: Uses @react-native-ml-kit/face-detection or Google ML Kit Flutter package to output 128-d vector embeddings.
DBSCAN Clustering: Calculates Cosine Distance between embeddings. Distance ≤ 0.38 auto-clusters photos into a single person profile.
Scene & Object Classifier: Runs EfficientNet-Lite4 via TensorFlow Lite (Android) and CoreML (iOS) for scene tags (Beach, Food, Pet, Document).

3. CLI Setup Instructions

Build and launch local development target:

  1. git clone https://github.com/flexigallery/app.git
  2. cd flexigallery && npm install
  3. npx pod-install ios
  4. npx react-native run-ios
  5. npx react-native run-android
Permissions Guard: Requires READ_MEDIA_IMAGES on Android 13+ and NSPhotoLibraryUsageDescription on iOS.
